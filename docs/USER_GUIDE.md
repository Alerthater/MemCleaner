# MemCleaner 使用说明（v1.1.1）

- 开源仓库：https://github.com/Alerthater/MemCleaner
- 下载与更新：https://github.com/Alerthater/MemCleaner/releases
- 许可：MIT License（代码）；来源声明与第三方致谢见仓库 `NOTICE.md`；隐私/安全政策见 `PRIVACY.md` / `SECURITY.md`。

一个极简、超低占用的 Windows 内存清理工具。清理能力与 PCL 启动器的「内存优化」完全一致，
界面为 Windows 11 / macOS 风格的无边框自绘窗口。

## 一、快速开始

1. 双击 `MemCleaner.exe`。窗口出现，显示当前内存使用率。
2. 点击 **清理内存**：
   - 若当前是普通权限：会先弹出应用内确认框，确认后 Windows 会弹出一次 UAC，
     点「是」后程序以管理员身份重新启动并自动执行清理；
   - 若已经是管理员模式：直接执行清理，窗口里会显示本次清理效果。
3. 清理完成后窗口会显示本次清理释放的缓存量与可用内存变化（如「已清理 2.8 GB 缓存，可用内存 +1.2 GB」）。

## 二、v1.1.1 修复：开机自启

v1.1.1 专门修复「开机自启无法正常运行」：后台计划任务被外部删除/程序移动后，程序启动时会自动检查并重建；
任务路径含空格时不再因引号导致启动失败；登录时若 Explorer 尚未就绪，托盘图标会自动重试（Explorer 重启后也会自动恢复）。
详见「常见问题 → 开机自启没生效怎么办」。

## 三、v1.1.0 新功能

### 1. 托盘图标显示内存占用率
设置 → 通用 →「托盘图标显示占用率」开启后，任务栏通知区域的图标会直接显示当前内存百分比，
并按内存压力变色（<75% 蓝色、75–89% 琥珀色、≥90% 红色）。关闭则恢复普通应用图标。
（若图标被 Windows 收进托盘溢出区，可点任务栏「∧」展开查看。）

### 2. 自动清理阈值直接输入（30%–100%）
设置 → 通用 → 点「触发阈值」行，在输入框中直接输入数字（首次输入会自动替换旧值），
按 Enter 保存、Esc 取消；鼠标滚轮悬停在阈值行上可 ±1 微调。输入超出 30–100 会自动收敛到范围内。

### 3. 外观与换肤（设置 → 外观）
- **配色方案**：极光蓝 / 薄荷绿 / 紫罗兰 / 琥珀橙 / 樱粉 / 石墨灰，点击行循环切换；
- **背景皮肤**：默认 / 极光 / 星云 / 晨雾 / 暮色（程序化背景，不占额外内存）；
- **自定义图片皮肤**：点「选择自定义图片」从本机选择 PNG/JPG/BMP/GIF/WebP，
  程序会按窗口比例裁切填充并叠加可读性遮罩；「清除自定义皮肤」恢复默认；
- **透明度**：
  - 皮肤不透明度（0–100）：自定义/预设背景的叠加强度；
  - 面板不透明度（20–100）：卡片、分隔线、悬停底色的透明度；
  - 窗口不透明度（50–100）：整个窗口的真实透明（分层窗口），可看到桌面背景；
- 底部有配色实时预览，当前方案会高亮。

### 4. 修复：收缩文件缓存
v1.0.0 勾选「收缩文件缓存」会导致整次清理失败（缺少 `SeIncreaseQuotaPrivilege`）。
v1.1.0 已修复：执行前自动启用该特权，管理员实测 `TrimFileCache` 成功。
如勾选后仍失败，请确认程序以管理员身份运行（普通权限无法收缩系统文件缓存）。

## 四、推荐设置（免 UAC、自动清理）

内存清理必须管理员权限才能生效。为了避免每次点清理都弹 UAC：

1. 以管理员模式打开程序（第一次点清理时确认 UAC 即可）；
2. 打开右上角 ⚙ 设置页，开启 **开机自启**：
   程序会创建一个「以最高权限运行」的计划任务；
3. 之后每次登录 Windows 都会静默启动到托盘，自动清理无需任何弹窗。

设置页里可以：
- 开关 **自动清理**（默认按内存占用 ≥85% 触发，两次之间至少间隔 60 秒）；
- **直接输入** 30–100 之间的触发阈值；
- 选择清理项：**清空工作集 / 刷新已修改页面 / 清除待机列表**（这三项 = PCL 启动器的内存优化），
  进阶可选 **低优先级待机列表 / 收缩系统文件缓存**；
- 切换深色 / 浅色 / 跟随系统主题；
- 开关托盘图标占用率显示。

> 说明：为保持界面简洁，两个进阶开关只存在配置文件
> `%LOCALAPPDATA%\MemCleaner\config.json` 中：`minimize_to_tray`（默认 true，关闭窗口时最小化到托盘）
> 与 `animations`（默认 true），可用文本编辑器修改后重启生效。

## 五、托盘

- 关闭窗口（✕）默认只是最小化到托盘，程序继续在后台运行（自动清理仍有效）；
- 托盘图标右键菜单：打开主界面 / 立即清理 / 退出；
- 要彻底退出，请用托盘菜单的「退出」，或在设置页关闭「关闭时最小化到托盘」后再点 ✕。

## 六、卸载 / 恢复

- 便携软件，删除 `MemCleaner.exe` 即可；
- 若开过「开机自启」，请先在设置页关闭，或在管理员 PowerShell 中执行：
  `MemCleaner.exe --uninstall-autostart`
- 配置文件在 `%LOCALAPPDATA%\MemCleaner\config.json`，删除即恢复默认
  （自定义皮肤仅保存图片路径，不会复制图片文件）。

## 七、常见问题

**Q：为什么清理时偶尔会卡一下？**
清空待机缓存/文件缓存后，短时间内再次读写文件需要重新读盘，属于正常现象
（PCL 的「内存优化」也有同样效果，机械硬盘更明显）。建议不要在大型游戏、编译、拷贝文件时清理。

**Q：清理会影响正在运行的程序吗？**
不会结束任何进程。它只回收「工作集」和「可回收的缓存页」，程序随后会按需重新加载。

**Q：占用多少内存？**
Release 版空闲常驻约 **3.7 MB**（Private），远低于常见内存清理工具；空闲时 CPU 接近 0。
使用自定义图片皮肤时会额外占用约 2–3 MB 作为图片解码缓存（仅该功能开启时）。

**Q：窗口透明度调低后圆角还在吗？**
在。窗口透明度使用分层窗口实现，程序会同步用圆角窗口区域兜底，Win11 下观感正常。

**Q：开机自启没生效怎么办？**
1. 先看任务是否存在：在命令行运行 `MemCleaner.exe --autostart-status`，
   显示 `status=installed` 且 `exe=` 是你现在用的程序路径即为正常；
2. 若显示 `not-installed` 或路径不一致：以管理员身份启动一次程序（点一下「清理内存」会触发 UAC 提权），
   v1.1.1 会在启动时自动重建任务；或在设置页把「开机自启」关掉再打开；
3. 任务存在但仍未随开机启动：检查 Windows「任务计划程序」中 `MemCleaner AutoStart` 是否被禁用，
   或安全软件是否拦截了计划任务；
4. 排查日志：`%LOCALAPPDATA%\MemCleaner\memcleaner.log`（若该目录不可写，会写到程序同目录的
   `memcleaner.log`），里面会记录启动参数、权限、托盘图标添加结果和自启任务状态。
5. 若你移动过 `MemCleaner.exe` 的位置：下次以管理员权限启动时会自动把任务更新到新路径。

**Q：Windows 10 能用吗？**
可以。圆角/阴影是 Win11 特性，Win10 上会退化为直角无阴影，其它功能一致。需要 64 位系统。

## 八、命令行（可选）

```
MemCleaner.exe                          启动主界面
MemCleaner.exe --autostart              静默启动到托盘（计划任务使用）
MemCleaner.exe --self-test --out x.json 命令行自检（管理员下执行会真正清理并输出 JSON 结果）
MemCleaner.exe --self-test --with-file-cache  自检附带「收缩文件缓存」项（验证用）
MemCleaner.exe --install-autostart      安装开机自启计划任务（需管理员）
MemCleaner.exe --uninstall-autostart    卸载（需管理员）
MemCleaner.exe --autostart-status       查看开机自启计划任务状态（是否安装/指向哪个 exe）
MemCleaner.exe --version / --help
```

## 九、安全说明

- 清理只回收可回收的缓存与工作集，不写注册表、不结束进程、不改系统文件；
- 「开机自启」只是在 Windows 计划任务里创建一个名为 `MemCleaner AutoStart` 的登录任务，
  可随时在设置页关闭；
- 程序不联网、不上传任何数据；自定义皮肤图片只在本机读取，不会复制或上传。
