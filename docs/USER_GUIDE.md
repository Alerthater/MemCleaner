# MemCleaner 使用说明

- 开源仓库：https://github.com/Alerthater/MemCleaner
- 下载与更新：https://github.com/Alerthater/MemCleaner/releases
- 许可：MIT License（代码）；来源声明与第三方致谢见仓库 `NOTICE.md`；隐私/安全政策见 `PRIVACY.md` / `SECURITY.md`。

一个极简、超低占用的 Windows 内存清理工具。清理能力与 PCL 启动器的「内存优化」完全一致，
界面为 Windows 11 / macOS 风格的无边框自绘窗口。

## 一、快速开始

1. 双击 `MemCleaner.exe`。窗口出现，显示当前内存使用率。
2. 点击 **清理内存**：
   - 若当前是普通权限：会先弹出应用内确认框，确认后 Windows 会弹出一次 UAC，
     点「是」后程序以管理员身份重新启动并自动执行清理；
   - 若已经是管理员模式：直接执行清理，窗口里会显示本次清理效果。
3. 清理完成后窗口会显示本次清理释放的缓存量与可用内存变化（如「已清理 2.8 GB 缓存，可用内存 +1.2 GB」）。

## 二、推荐设置（免 UAC、自动清理）

内存清理必须管理员权限才能生效。为了避免每次点清理都弹 UAC：

1. 以管理员模式打开程序（第一次点清理时确认 UAC 即可）；
2. 打开右上角 ⚙ 设置页，开启 **开机自启**：
   程序会创建一个「以最高权限运行」的计划任务；
3. 之后每次登录 Windows 都会静默启动到托盘，自动清理无需任何弹窗。

设置页里可以：
- 开关 **自动清理**（默认按内存占用 ≥85% 触发，两次之间至少间隔 60 秒）；
- 调整触发阈值；
- 选择清理项：**清空工作集 / 刷新已修改页面 / 清除待机列表**（这三项 = PCL 启动器的内存优化），
  进阶可选 **低优先级待机列表 / 收缩系统文件缓存**；
- 切换深色 / 浅色 / 跟随系统主题。

> 说明：为保持界面简洁，设置页只放最常用的 9 项。两个进阶开关只存在配置文件
> `%LOCALAPPDATA%\MemCleaner\config.json` 中：`minimize_to_tray`（默认 true，关闭窗口时最小化到托盘）
> 与 `animations`（默认 true），可用文本编辑器修改后重启生效。

## 三、托盘

- 关闭窗口（✕）默认只是最小化到托盘，程序继续在后台运行（自动清理仍有效）；
- 托盘图标右键菜单：打开主界面 / 立即清理 / 退出；
- 要彻底退出，请用托盘菜单的「退出」，或在设置页关闭「关闭时最小化到托盘」后再点 ✕。

## 四、卸载 / 恢复

- 便携软件，删除 `MemCleaner.exe` 即可；
- 若开过「开机自启」，请先在设置页关闭，或在管理员 PowerShell 中执行：
  `MemCleaner.exe --uninstall-autostart`
- 配置文件在 `%LOCALAPPDATA%\MemCleaner\config.json`，删除即恢复默认。

## 五、常见问题

**Q：为什么清理时偶尔会卡一下？**
清空待机缓存/文件缓存后，短时间内再次读写文件需要重新读盘，属于正常现象
（PCL 的「内存优化」也有同样效果，机械硬盘更明显）。建议不要在大型游戏、编译、拷贝文件时清理。

**Q：清理会影响正在运行的程序吗？**
不会结束任何进程。它只回收「工作集」和「可回收的缓存页」，程序随后会按需重新加载。

**Q：占用多少内存？**
Release 版常驻约 3~5 MB（Private），远低于常见内存清理工具；空闲时 CPU 接近 0。

**Q：Windows 10 能用吗？**
可以。圆角/阴影是 Win11 特性，Win10 上会退化为直角无阴影，其它功能一致。需要 64 位系统。

## 六、命令行（可选）

```
MemCleaner.exe                         启动主界面
MemCleaner.exe --autostart             静默启动到托盘（计划任务使用）
MemCleaner.exe --self-test --out x.json 命令行自检（管理员下执行会真正清理并输出 JSON 结果）
MemCleaner.exe --install-autostart     安装开机自启计划任务（需管理员）
MemCleaner.exe --uninstall-autostart   卸载（需管理员）
MemCleaner.exe --version / --help
```

## 七、安全说明

- 清理只回收可回收的缓存与工作集，不写注册表、不结束进程、不改系统文件；
- 「开机自启」只是在 Windows 计划任务里创建一个名为 `MemCleaner AutoStart` 的登录任务，
  可随时在设置页关闭；
- 程序不联网、不上传任何数据。
